# Protocol: Deep Sleep (Unity 6, Meta Quest)

Single-player VR escape room on the research vessel Aethelgard. Study: does spatial (HRTF) voice
guidance cut evacuation time and wrong turns in smoke-filled egress, compared with stereo?

Open this folder as a Unity 6000.5.2f1 project. Scene: Assets/_Project/Scenes/SCN_Main.unity.
Docs: Assets/_Project/Docs. Analysis: Analysis/, Tools/. Screenshots are omitted to keep the repo small.
