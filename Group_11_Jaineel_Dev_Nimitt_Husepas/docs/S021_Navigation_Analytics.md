# S021 Navigation Analytics

## Ownership

`S021NavigationAnalytics` is an independent subscriber. It consumes `IS014NavigationEvents`, `IS014RouteProvider`, and `IS014PoseProvider`; it does not modify S014 navigation state or depend on a concrete route-controller implementation.

## Implemented behavior

- **IMPLEMENTED:** Perpendicular distance from the current pose to the active planned route segment.
- **IMPLEMENTED:** Configurable deviation threshold and one count per deviation excursion.
- **IMPLEMENTED:** Wrong-turn count aligned with deviation-entry events.
- **IMPLEMENTED:** Navigation event subscription with enable/disable unsubscription.
- **IMPLEMENTED:** Session metrics for participant ID, condition, duration, deviation count, wrong-turn count, total distance, target floor, NASA-TLX, and SUS.
- **IMPLEMENTED:** Culture-invariant CSV serialization with header and field escaping.
- **TESTED:** Deterministic route/deviation behavior is covered by source-level validation; Unity Play Mode validation requires the Group 11 folder to be opened as a Unity project.
- **MOCKED:** The default participant and condition values are explicitly `MOCK-TEST` and `MOCK`. They are not study results.
- **INTEGRATION-READY:** A scene can assign any components implementing the three S014 interfaces.
- **NOT-YET-IMPLEMENTED:** Persistence/storage destination, CSV file rotation, and real participant/session entry UI.

No empirical participant records, SUS/NASA-TLX scores, p-values, effect sizes, or economic outcomes are generated by this component.
