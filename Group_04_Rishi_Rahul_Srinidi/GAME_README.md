# Cyber Security Escape Room VR: The Northwind Breach

A story-driven VR cyber-security game for **Meta Quest**, built with **Unity 6 (6000.6)**, URP and the Meta XR SDK. You play a new **blue-team analyst** on your first night shift. Maya, your SOC lead, guides you over the radio through three chapters, from spotting the first alert to closing the incident.

The full story takes about 25-40 minutes and teaches 22 learning points. Progress, best times and learning points are saved between sessions.

## Story

| # | Chapter | Where | What you do |
|---|---|---|---|
| 1 | **Night Shift** | SOC control room | Learn the controls, open the SIEM alert, read the logs, identify the attack, escalate, and badge through the door |
| 2 | **Fred's Office** | Floor 3 | Escape room against the clock: evidence handling, shredding, USB bait, password guessing and reset, 2FA, phishing, social engineering, encryption, and the door code |
| 3 | **The Server Room** | Basement data centre | Find and unplug the rogue implant, bag it, quarantine its switch port, restore a clean backup, and file the incident report |

## Features

- Three guided incident-response scenes plus a main menu, all playable with controllers, hands, or the Meta XR Simulator.
- Physical puzzles: grab evidence, shred documents, quarantine a USB stick, drop items into the right container (wrong drops are explained, not just rejected).
- In-world monitors with tabs, an on-screen keyboard and a live password-policy checker.
- Voice-over and subtitles for Maya, a green guidance marker, an objective on your wrist and three-tier hints (nudge, direction, answer).
- Run timer, game-over retry, completion certificate and a comfort dim for locomotion.
- Saved progress, best times and a learning-points log.

## Getting started

**Requirements:** Unity `6000.6.2f1`, the Android Build Support module (for Quest), and a Meta Quest 3 or the Meta XR Simulator.

1. Clone the repo and open the folder in Unity Hub. The first import regenerates `Library/`, which takes a while.
2. **Simulator:** open `Assets/_Project/Scenes/MainMenu.unity`, enable the Simulator from the Meta XR toolbar and press Play.
3. **Quest 3:** *File > Build Profiles > Meta Quest > Switch Platform*, fix any "Required" items in *Meta > Tools > Project Setup Tool*, then *Build And Run*.
4. **Rebuild every scene:** *CSER > Build All Scenes (story mode)* regenerates and bakes all four scenes from code (a few minutes on a GPU).

See [HOW_TO_PLAY.md](HOW_TO_PLAY.md) for a step-by-step walkthrough of each chapter.

## Tech notes

- **Scenes are generated by code** (`Assets/_Project/Scripts/Editor/EscapeRoomBuilder.cs` and `StoryBuilder.cs`), so they are reproducible. Don't hand-edit them; change the builders and rebuild.
- Interaction uses the Meta Interaction SDK Quick Actions: the comprehensive rig, ray and poke canvases, grab and distance grab, teleport hotspots.
- Lighting is baked (area lights, AO, light probes, a box-projected reflection probe) plus one mixed spot for held-object shadows. Post-processing (ACES, bloom, grading) runs on PC; on Quest it is switched off and foveated rendering is on (`PlatformTuning.cs`).
- **No flicker:** camera near/far is 0.05 m / 60 m for depth-buffer precision, and labels and decals sit at least 1 mm off their surfaces.
- Voice-over: `Tools/generate_vo.ps1` regenerates every line in `Resources/VO/narration.json` using Windows speech synthesis.
