## Inspiration
Gameplay structure, UI style (rounded white cards, mint/blue headers, learning points, hint system) and colour palette are **inspired by** the 2D WebGL game *Cyber Security Escape Room Online*. No assets, code or text from that product are used. All puzzle content, story (a blue-team incident-response scenario) and writing are original.
